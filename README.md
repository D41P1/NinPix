## info on Combat rollback principle 
always when Buffering the CurrentPlayerState Buffer the State they end up in
in other words DO NOT buffer the PlayerState with a State and Action when that Action will just change the State and the action  
so if the State and action is Weapon, Block this Action will immediately change the PlayerState into Blocking, Guard therefore the thing i am supposed to buffer is Blocking, Guard Cos this action will not immediatley change into another Action
